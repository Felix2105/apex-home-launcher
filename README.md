# APEX Home Launcher

An Android launcher prototype with an executive navy-and-gold interface.

## Features
- Android Home launcher entry
- App drawer for installed launchable apps
- Shortcuts to the local APEX Dashboard and Business HQ
- GitHub Actions workflow to build and publish the debug APK as an artifact

## Build
Open the repository's Actions tab and run **Build APEX Launcher APK**.
Download the `APEX-Launcher-APK` artifact after the workflow succeeds.

The dashboard shortcuts work when the APEX services are running on the same phone.
